# Peek Viewer — Crash & Missing/Wrong-Size Image Fixes (2026-07-22)

Diagnosed from `%TEMP%\rfab_viewer.log` and Windows Event Log (Application, IDs 1000/1002).

## What was actually happening

### 1. "Missing" images and wrong relative sizes in grid mode — stuck `_resize_active` flag
`ResizeMixin._resize_mouse_press` uses native `startSystemMove()` / `startSystemResize()`.
Native window moves/resizes are handled by Windows, so **the widget never receives a
`mouseReleaseEvent`**. `GridView.mousePressEvent` set `self._resize_active = True` on every
title-zone drag or edge resize, and only `mouseReleaseEvent` reset it — so after one drag the
flag was stuck True forever.

Consequence: `GridCell.resizeEvent` early-returned while `_resize_active`, so:
- cells added afterwards (drag-drop, merge, arrow-key navigation) never got their pixmap
  → **black "missing" images**;
- cells resized afterwards kept their stale old-scale pixmap
  → **images too small or too big relative to the others**.

Log evidence: `SYSTEM MOVE: pos=958,27` at 14:18:42 followed by new cells with no re-render.

Fix:
- `_resize_mouse_press` now returns `'system'` vs `'manual'` (both truthy); `GridView` and
  `ImageViewer` only hold `_resize_active` for manual (tracked) drags.
- `GridCell.resizeEvent` never skips rendering anymore: it renders with
  `FastTransformation` while a resize/drag is in flight and `SmoothTransformation` otherwise.
- `GridView` runs a debounced (150 ms) `_finalize_resize()` smooth pass after resizes settle
  (repurposed the previously dead `_layout_timer`).

### 2. Missing images after Unzip+Flatten — trailing-space ZIP names
ZIPs named like `Foo .zip` (space before extension) produced `extract_dir = "Foo "` —
Windows strips trailing spaces on mkdir, so every member write failed with
`[Errno 2] No such file or directory` and **the whole archive's images never appeared**
(seen twice in today's log). Fixed with `safe_extract_dir()` in `peek/unzipper.py`
(strips trailing spaces/dots, falls back to `extracted`); also used by `_unzip_single`.

### 3. Dedup could delete non-duplicates
The duplicate finder hashed only size + first/last 64 KB, then deleted matches. A collision
would silently delete a file that wasn't a duplicate (another "missing images" vector).
Now every candidate is verified with a **full-content MD5** against its matched original
before it's offered for deletion; false positives are logged and kept.

### 4. "Crashes" were mostly a UI-thread hang (Event 1002, 7/19)
Unzip used `extractall()` (blocks for the whole archive), and Unzip+Flatten ran
`flatten_folder` with **no progress callback** — thousands of file moves with zero event
pumping → "RFab Viewer.exe stopped interacting with Windows and was closed".
Fixes: member-by-member extraction with progress pumping every 25 files; flatten now pumps
events every 20 files through the unzip progress bar.

Note: the June 26 `Qt6Core.dll 0xc0000409` crash reports in Event Log came from an old build
(`C:\Users\Merry\dev\peek-viewer`); the `CONVERT_TO_GRID` crashes in the log (`_file_path`,
`_log` NameError) were already fixed in current source.

### 5. Grid rows now balanced
`_compute_rows` chunked sequentially (5 images @ 4 cols → 4+1), making the lone last-row
image render enormous. Rows are now balanced (5 → 3+2, 9 → 3+3+3) so panels stay
near-equal, matching the README's "equal-sized panels" promise.

### 6. GIFs scaled without aspect ratio (overflowed/stretched next to images)
Every `QMovie` site called `setScaledSize(QSize(w, h))` with the full cell/window size,
stretching the GIF to fill its container while plain images were aspect-fitted — so GIFs
looked blown up / spilling past their panel next to images. All five sites (grid cell
setup/resize/replace, image viewer load/resize) now read the GIF's native size once
(`QImageReader` header, `_movie_native_size()` in grid_view.py) and scale through
`fit_size()`; center-aligned labels letterbox the remainder.

## Files changed
- `peek/resizable.py` — `_resize_mouse_press` returns `'system'`/`'manual'`
- `peek/grid_view.py` — stuck-flag fix, always-render cells, debounced smooth pass, balanced rows
- `peek/image_viewer.py` — stuck-flag fix
- `peek/unzipper.py` — `safe_extract_dir()`, member-wise extraction with pumping
- `peek/main.py` — `_unzip_single` safe dir, flatten progress pumping, dedup full-hash verify

Rebuilt via `python -m PyInstaller "RFab Viewer.spec"`.
